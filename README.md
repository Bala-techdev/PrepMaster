# PrepMaster
PrepMaster is a gamified software engineering preparation platform featuring structured DSA practice, Java OOP learning, system design, mock interviews, daily challenges, streaks, and progress analytics.



# PrepMaster 🚀

### Level Up Your Software Engineering Skills

PrepMaster is a full-stack, gamified software engineering preparation platform designed to help students and aspiring developers build consistent learning habits and prepare for technical interviews.

## 🎯 Project Vision

To provide a structured, interactive, and motivating learning experience for mastering Data Structures and Algorithms, Object-Oriented Programming, System Design, and technical interview skills.

## ✨ Features

### Core Platform
- Modern, responsive learning dashboard
- Personalized daily learning plans
- Structured DSA practice
- Java OOP learning modules
- System design preparation
- Learning progress visualization

### Gamification
- Daily streak tracking
- XP and leveling system
- Daily challenges and deadlines
- Activity heatmaps
- Progress analytics

### Interview Preparation
- Timed mock interviews
- Interview question practice
- Performance tracking

### User Experience
- User registration and login
- Personalized profile and settings
- Responsive desktop and mobile layouts
- Theme preferences

**Note:** PrepMaster is under active development. Some features listed above are planned or partially implemented.

## ⚙️ Local Development

### Prerequisites

- Java 21
- Node.js and npm
- MySQL
- Git

### Frontend

```bash
cd frontend
npm install
npm run dev -- --port 5180 --strictPort
```

Frontend URL: http://localhost:5180

### Backend

```bash
cd backend
mvnw.cmd spring-boot:run
```

Default backend URL: http://localhost:8080

Configure the database connection and required environment variables before running the backend.
